Trabajo Práctico N°3 - Sockets (Cerna)

Proyecto: tp-3-cerna-sockets
Descripción: Transmisión de archivos cliente-servidor utilizando sockets TCP en Java.

Instrucciones:
1. Compilar ambos archivos:
   javac Server.java
   javac Client.java

2. Ejecutar el servidor:
   java Server

3. Ejecutar el cliente:
   java Client

4. Seleccionar archivos mediante el cuadro de diálogo.
5. Los archivos recibidos se guardan en la carpeta 'received_files' en el servidor.
